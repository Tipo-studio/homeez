Quick start

Make your first request using an API key with StarShort access.

Base URL

https://api.ezvid.net View API reference

Search StarShort

curl --request GET \
  'https://api.ezvid.net/api/starshort/search?keyword=love' \
  --header 'X-API-Key: YOUR_API_KEY'

Replace YOUR_API_KEY with your key and send the request from your server.
